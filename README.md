# アタマップ（ATAMAP）

友だちの「頭の中の地図」を当てるパーティーゲーム。

## 遊び方

1. 主役が、お題の5つのワードを縦×横の2軸マップに置く。
2. ほかの全員が「主役ならココらへん」とピンを置いて当てる。
3. 1ワードずつ答え合わせ。主役の置き場所に近いほど高得点（距離10以内で3点、20以内で1点）。

- 3〜8人、1ラウンド約3分
- 各自のスマホのブラウザで、URLかQRコードから参加（アプリのインストールは不要）
