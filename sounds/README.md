# 効果音について

このフォルダの音は、[効果音ラボ](https://soundeffect-lab.info/) の素材です。アタマップの操作の音として使っています（後ろの無音を短くし、ファイルを小さくしています）。

効果音ラボの利用規約により、ここから音を取り出して、ほかで使ったり配ったりすることはできません。使いたいときは、効果音ラボから直接ダウンロードしてください。
