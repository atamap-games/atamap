# 「アタマップ」ゲーム仕様書 v0.1

> これは Claude Docs にある仕様書の写し（2026-11-06 時点）。元の仕様書が見られないときは、これを正とする。

## 概要

『アタマップ』（英語表記：ATAMAP）は、お題の5つを縦×横の2軸マップに置き、友だちの置き場所を当てるパーティーゲーム。1回約3分、3〜8人で、各自のスマホのブラウザから遊ぶ。名前は「頭（アタマ）」と「地図（マップ）」を合わせた造語で、日本と海外で同じ名前を使う。

| 項目 | 内容 |
| --- | --- |
| ジャンル | 2軸マップ当て（価値観を当てるパーティーゲーム） |
| 人数 | 3〜8人（配信者モードは配信者1人＋視聴者） |
| 時間 | 1ラウンド約3分。4人なら1ゲーム約15分 |
| 遊ぶ場所 | 同じ部屋、または通話しながら |
| 端末 | スマホのブラウザ。URLかQRで参加し、インストールは不要 |
| 対象 | 10〜20代の友だちグループ、配信者と視聴者、飲み会の幹事 |
| 最初の公開 | 2026年11月（ブラウザ版の試作。本物のスマホでの試遊のあとに公開を告知） |

## 基本ルール

1ゲーム＝全員が1回ずつ主役になる。主役を1人ずつ順番に回し、「主役がマップを作る → ほかの人が予想 → 答え合わせ」をくり返す。1人分ずつ区切って進むので、テンポがよい（2026年11月6日にユーザーの希望で変更。前は、はじめに全員が同時にマップを作る流れだった）。

1. **部屋に集まる**：ホストが部屋を作り、ほかの人はQRかURLから名前を入れて参加する（3〜8人）。1台のスマホを回して遊ぶこともできる（トップの「1台で遊ぶ」）。制限時間は「90秒／なし」から選ぶ（部屋ならホストが待合室で、1台なら名前を入れる画面で）。
2. **主役のお題を発表**：順番に1人が主役になり、その人のお題・2本の軸・5つのワードを大きな札で発表する。
3. **主役がマップを作る**：主役は5つを自分の感覚でマップに置いてロックする。お題が嫌なら1回だけ引き直せる。部屋で遊ぶときは、そのあいだ、ほかの人には主役の名前・お題・5つのワードを先に見せる（置き場所は秘密。引き直すと変わる）。
4. **予想する**：主役以外の全員が、5つそれぞれ「主役ならココらへん」とピンを置く。全員がそろうか、締め切りの3秒後に答え合わせへ進む（ホストは「待たずに進める」も押せる）。
5. **答え合わせ**：1ワードずつ、みんなの予想のピンを0.5秒ごとに1本ずつ出す。出そろったら主役が「答えを見る！」を押し、スポットライトがマップの上をめぐる「ドキドキ…」の演出（5秒）のあとで、主役の答えのピン（名札は「ココらへん！」）が落ちてきて点数がつく。主役はみんなの予想にコメントする（任意）。答え合わせを進めるボタンは主役のスマホだけにある。
6. **次の主役へ**：全員が1回ずつ主役をするまで2〜5をくり返す。
7. **表彰**：合計点と賞を発表し、結果画像を保存・投稿できる。

マップは方眼紙の見た目（1マス＝10。3点が取れるのは、だいたいとなりのマスまで）。ピンはマスに吸いつかず、どこにでも置ける。中身は縦横0〜100の座標として扱う。

### 時間切れと、部屋で遊ぶときの決まり

- 時間切れのとき、主役のマップは、置いていないワードを真ん中に置いたことにする。予想は、置いていないワードを0点にする。
- ゲームが始まったあとは、新しい人は入れない。開き直した本人は、自動で部屋にもどれる。
- 主役がいなくなった（通信が切れた）ときは、ホストが代わりに進められる。マップ作りの番なら「この主役をとばす」を押せる。
- ホストが部屋を出ると、部屋は閉じる。

## 点数の決め方

点数は、主役のピンと予想のピンの距離だけで決まる。マップは縦横0〜100として計算する。

| 判定 | 主役のピンとの距離 | 点 |
| --- | --- | --- |
| ど真ん中 | 10以内 | 3点 |
| 近い | 10より遠く20以内 | 1点 |
| はずれ | 20より遠い | 0点 |

1ラウンドの最高は15点（5ワード×3点）。主役はそのラウンドでは点をもらわない。距離の10・20は仮の値で、試遊で決め直す。

| 賞 | 決め方 |
| --- | --- |
| 以心伝心王 | 予想の合計点がいちばん高い人 |

同点のときはどちらも受賞。3人以上が同点なら「〇人が同点」と出す。

## お題の作り方のルール

お題は「お題名・2本の軸・5つのワード」の3点セット。縦を気持ち、横をその人の行動や経験にすると、どのワードも迷わず置けて、人によって置き場所が変わる。

- **縦の軸は気持ち**：上が前向き（好き、やりたい、欲しい）、下が後ろ向き（苦手、やりたくない、いらない）。
- **横の軸はその人の行動・経験・できること**：左が「する・ある・できる」（よく食べる、家で出てた、自分で作れる）、右が「しない・ない・できない」。
- **「安そう↔高そう」「子どもっぽい↔大人っぽい」のような横軸は使わない**：常識で答えが決まり、全員が同じ場所に置いてしまう。
- **4つの角がそのまま会話のネタになる**：右上は「好きなのにやってない」、左下は「苦手なのにやってる」。
- **ワードは5つ**：10〜20代の誰もが知っていて、食べたり見たりしたことがあるもの。
- **長さ**：ワードは8文字以内、軸の端は6文字以内（スマホのピンと画面の端に収めるため）。
- **入れないもの**：実在の人物や遊んでいるプレイヤー本人、容姿をくらべる軸、政治・宗教、下ネタ、病気、恋愛の経験、お酒とたばこ（10代も遊ぶため）、商品名・店名（一般名にする）。

### お題を入れる前の4つのチェック

1. **全員が知っている**：10〜20代の誰もが知っていて、経験がある。地域や年代で知らない人がいるものは外す。
2. **どのワードも両方の軸に置ける**：苦手なワードやしたことがないワードでも、迷わず置ける。
3. **横軸が常識で決まらない**：人によって答えが変わる軸になっている。
4. **全員が同じ場所に置くワードがない**：2本の軸のどちらかで、人によって置き場所がはっきり変わる。

## 12月の試作で作るもの・作らないもの

試作はパーティーモードだけ。同じ部屋で最後まで遊べて、結果画像を投稿できれば合格とする。

### 作る

- [ ] 部屋を作る・QRとURLで各自のスマホから参加（3〜8人、名前だけ、アカウントなし）
- [ ] 全員同時に自分のマップを作る画面（ドラッグで置く・置き直す・ロック）
- [ ] お題の引き直し（1回）
- [ ] 主役を順番に回す進行と90秒のタイマー
- [ ] 予想の画面と、1ワードずつの結果発表
- [ ] 採点（距離10以内3点、20以内1点）と最後の表彰
- [ ] 結果画像の保存と、Xに投稿するボタン（#アタマップ）
- [ ] お題50個の組み込み（この仕様書の表）
- [ ] ワードごとの置き場所を記録し、全員が同じ場所に置いたワードを見つける（お題の入れ替えに使う）

### 作らない（あとで）

- 配信者モード（2027年1〜2月）
- AIおまかせお題・自作お題・みんなの真ん中（第2弾）
- アカウント、課金、広告、ランキング
- アプリ版・Steam版
