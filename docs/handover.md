## 1. 新しいアカウントで再開する手順（ユーザーがやること）

1. **古いアカウントの自動タスクを止める**
   古いアカウントの claude.ai で、自動タスクの一覧から「アタマップX投稿下書き」をオフにする。両方のアカウントで動くと、下書きが2回届く。（「アタマップ毎日開発」は 2026-11-06 にすでに止めてある。）
2. **新しいアカウントに GitHub をつなぐ**
   新しいアカウントの claude.ai の設定にあるコネクタから GitHub をつなぐ。ログインするのは、atamap-games の持ち主と同じ GitHub ユーザー。書き込みができないと言われたら、https://github.com/apps/claude/installations/select_target で atamap-games を選び、リポジトリ `atamap` へのアクセスを許可する。
3. **新しい会話で、次の文をそのまま送る**

   ```
   GitHub の atamap-games/atamap を追加して、dev ブランチの docs/handover.md を読んで。そこに書いてある手順で、Xの下書きの自動タスクを作り直して、開発の続きをやって。返事は必ず日本語で。
   ```

4. **（必要なら）古いアカウントの企画スライドを PDF で保存しておく**
   スライドは古いアカウントの中にしかない。お金の計画（値段など）はスライドにだけ書いてある。このリポジトリは公開なので、ここには書いていない。
