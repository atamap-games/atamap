# アタマップ 引き継ぎ書

最終更新：2026-11-06

別の Claude アカウントや新しい会話で、アタマップの作業を続けるための資料。新しく担当する Claude は、まずこのファイルを最後まで読むこと。

## 1. 新しいアカウントで再開する手順（ユーザーがやること）

1. **古いアカウントの自動タスクを止める**
   古いアカウントの claude.ai で、自動タスクの一覧から「アタマップX投稿下書き」をオフにする。両方のアカウントで動くと、下書きが2回届く。（「アタマップ毎日開発」は 2026-11-06 にすでに止めてある。）
2. **新しいアカウントに GitHub をつなぐ**
   新しいアカウントの claude.ai の設定にあるコネクタから GitHub をつなぐ。ログインするのは、atamap-games の持ち主と同じ GitHub ユーザー。書き込みができないと言われたら、https://github.com/apps/claude/installations/select_target で atamap-games を選び、リポジトリ `atamap` へのアクセスを許可する。
3. **新しい会話で、次の文をそのまま送る**

   ```
   GitHub の atamap-games/atamap を追加して、dev ブランチの docs/handover.md を読んで。そこに書いてある手順で、Xの下書きの自動タスクを作り直して、開発の続きをやって。返事は必ず日本語で。
   ```

4. **（必要なら）古いアカウントの企画スライドを PDF で保存しておく**
   スライドは古いアカウントの中にしかない。お金の計画（値段など）はスライドにだけ書いてある。このリポジトリは公開なので、ここには書いていない。

## 2. 新しく担当する Claude が最初にやること

1. add_repo ツールで `atamap-games/atamap` を access「push」で追加して clone し、`dev` ブランチに切り替える（`git fetch --depth 50 origin dev`）。
2. README.md、CLAUDE.md（開発ルール）、PROGRESS.md（作る順番と進み具合）、docs/spec.md（仕様書の写し）、このファイルを読む。
3. 「5. 自動タスク」の「5-1. アタマップX投稿下書き」だけを、書いてある設定と文章のとおりに作り直す。作る前に、同じ名前のタスクがないか一覧で確かめる。開発は自動にしない（5-2 は作らない）。
4. ユーザーに、引き継ぎが終わったことと、次にやることを日本語で短く伝える。

## 3. ユーザーについて

- 返事は最初から最後まで必ず日本語。途中で英語に切り替わるのをとても嫌がる。報告、質問、タスク名、コミットメッセージも日本語。
- 専門用語は使わず、やさしい日本語で書く。画面のボタン名は、画面に出ているとおりに「」で書く。
- スマホから使うことが多い。長すぎる返事は読みにくい。
- お金がかからない方法を好む（X は API を使わず無料でやると決めている）。

## 手順
1. add_repo ツールで owner「atamap-games」、repo「atamap」を access「push」で追加し、その結果の指示どおりに1回だけ clone する。

- 決めたこと（仕様書に書いていなかったもの）：

  - 答え合わせ（2026-11-06 にユーザーの希望で変更）：1ワードずつ、予想のピンを0.5秒ごとに1本ずつ出す。出そろったら主役が「答えを見る！」を押し、スポットライトがマップの上をめぐる「ドキドキ…」の演出のあとで答えのピンが落ちてくる。主役がみんなの予想にコメントする時間を作るため。
  - 部屋で遊ぶとき：主役がマップを作っているあいだ、ほかの人には主役の名前・お題・5つのワードを先に見せる（引き直すと変わる）。主役がロックするか締め切りが来たら予想へ。予想は全員がそろうか、締め切りの3秒後に答え合わせへ（ホストは「待たずに進める」も押せる）。答え合わせを進めるボタンは主役のスマホだけにある。主役がホストでないときは、主役のスマホが部屋のデータの requests に「お願い」を書き、ホストのスマホがそれを見て進める。主役がいなくなった（通信が切れた）ときは、ホストが代わりに進められ、マップ作りの番なら「この主役をとばす」を押せる。ゲームが始まったあとは新しい人は入れない（開き直した本人は自動でもどれる）。ホストが部屋を出ると部屋は閉じる。
  - ミステリアス賞は「主役のとき、みんなが取れた点の合計」がいちばん低い人。今日のズレ大賞は「主役の答えとみんなの予想の距離の平均」がいちばん大きいワード（置かなかった予想は距離100）。3人以上が同点なら「〇人が同点」。
